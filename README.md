# Keyana

Keyana (Key Analyzer)，一款完全本地化的 Windows 键盘与鼠标使用分析工具，只统计次数，不记录内容。

它按分钟保存聚合计数，并提供时间范围、时段分布和全尺寸键盘热力图。1.3.1 起软件正式更名为 Keyana，解决方案、命名空间、程序集与数据文件名统一随之更新。

## 隐私原则

- 不记录输入内容；
- 不记录按键顺序；
- 不记录正在使用的应用或窗口；
- 不记录鼠标位置；
- 不需要账号，不连接服务器，不上传数据；
- 所有数据只保存在程序旁的 `Data` 目录。

## 主要功能

- Windows Raw Input 后台采集；
- 键盘按键、鼠标左右键 / 中键 / 侧键与滚轮上下刻度分别统计；
- 左右 Ctrl、Shift、Alt 等物理键分开计数；
- 长按自动连发去重；
- 每分钟聚合，30 秒自动保存；
- 今日、昨日、最近 10 分钟、近 7 日、近 30 日、全部和自定义范围；分析页另有
  全部 / 近 30 日 / 近 7 日 / 昨日 / 今日 快捷预设；
- 自定义区间用一个日历点两次确定起止日期，时间可用滚轮微调；
- 每日活跃有独立统计区间，与主范围重合的日期会高亮；柱内按 24 小时分段着色，
  能直接看出每天的时段分布；
- 活跃天数（每天 ≥325 次）与火热日（每天 ≥7999 次）按每日活跃区间统计；
  使用时长（有输入的分钟累计）双击可在「天 / 小时」两种最大单位间切换；
- 概览、分析、设置三个页面：键盘 + 鼠标热力图（鼠标按键与滚轮排在键盘下方）、十分钟时段、
  每日活跃、按键排行榜与类别占比；
- 热力图着色基准可分别为键盘、鼠标选择「键盘」「鼠标」「键盘 + 鼠标」，两边的量级不必互相迁就；
- 按键筛选：按类别多选 + 搜索，只看某几个键；概览与分析各自独立，可一键同步到另一页；
- 深色模式（可跟随系统）、字体族与字号倍率设置；
- CSV 导出；
- 系统托盘后台运行、暂停、立即保存和完整退出；设置页提供重启（可选普通 / 管理员权限）
  与带二次确认的完整退出；左下角常驻显示当前是普通权限还是管理员权限；
- 单实例运行和可选的当前用户登录自启动；
- 绿色版数据目录，可直接随程序文件夹迁移。

## 系统要求

- Windows 10 或更高版本；
- x64 处理器；
- 源码构建需要 .NET 10 SDK；
- 轻量发行版需要 x64 `.NET 10 Desktop Runtime`；完整自包含版无需预装运行时。

## 从源码构建

```powershell
dotnet restore .\Keyana.slnx
dotnet build .\Keyana.slnx -c Release --no-restore
dotnet run --project .\tests\Keyana.Core.Tests -c Release --no-build
```

生成完整自包含版和轻量版：

```powershell
.\scripts\publish.ps1
```

输出位于 `artifacts` 目录。

## 目录结构

```text
src/Keyana.Core/          键位模型、归一化和计数逻辑
src/Keyana.Storage/       SQLite、分钟聚合、设置与导出
src/Keyana.App/           WPF 界面、Raw Input 和托盘生命周期
tests/Keyana.Core.Tests/  无第三方测试框架的回归测试
docs/                       使用、构建、隐私和测试说明
scripts/                    发行包构建脚本
```

## 数据与迁移

数据保存在可执行文件旁的 `Data` 目录。迁移时完整复制程序文件夹即可。完整版和轻量版使用相同的数据格式。

数据库只保存每一分钟内各按键或按钮的累计次数，不保存事件顺序。更多说明见 [隐私与数据格式](docs/PRIVACY.md)。

## 游戏兼容性

普通桌面程序和大多数游戏可以使用 Raw Input 计数。如果游戏以管理员权限运行，请尝试以相同权限启动 Keyana。部分采用独占输入或反作弊隔离的游戏可能不会向普通桌面程序提供输入事件，本项目不会尝试绕过反作弊机制。
