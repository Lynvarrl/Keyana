# Keyana V1.3.5

Keyana 用于统计键盘按键、鼠标左右键 / 中键 / 侧键的使用次数，以及滚轮的**滚动距离**与
**上滑 / 下滑手势次数**。所有数据只保存在本机，不登录、不上传，也不记录输入内容、输入顺序、
使用中的应用或鼠标位置。

## 基本使用

- 运行 `Keyana.exe` 后即可开始采集；
- 关闭主窗口后程序会继续在系统托盘运行；
- 双击托盘图标可以重新打开统计窗口；
- 需要停止采集时，请从托盘菜单选择“完整退出”，或在设置页点「完整退出」；
- “暂停采集”不会删除已有记录；
- “清零本次显示”只影响本次运行，不删除历史数据。

## 页面

左侧导航分三页：

- **概览**：所选范围的总输入、活跃天数、使用时长、火热日、本次运行，以及键盘与鼠标热力图、
  十分钟时段分布、鼠标输入与滚轮距离 / 手势、每日活跃和实时采集状态；
- **分析**：独立的统计区间与快捷预设，提供按键排行榜（Top 30）、类别占比环形图、
  滚轮距离与手势、每日输入趋势和全部键位的累计次数；
- **设置**：主题（浅色/深色/跟随系统）、界面字体与字号、配色、色阶与热力图着色基准、
  滚轮采集与校准、开机自启（可选以管理员权限自启）、10 分钟吸附，以及数据文件的位置、
  大小、保存、导出、重启与完整退出。

## 侧边栏状态与权限

左下角的“正在采集 / 已暂停 / 保存异常 / 启动失败”表示采集状态，紧跟其后的小字表示
当前进程的权限：

- 「管理员权限」：以管理员权限运行的程序（如部分游戏）内的输入也会被统计；
- 「普通权限」：这些程序内的输入不会被统计。

这一行只读，进程启动后权限不会再变；需要切换请用设置页的「重启」或「完整退出」后重新打开。

## 时间范围

- 预设支持今日、昨日、最近 10 分钟、近 7 日、近 30 日、全部和自定义；
- “昨日”是完整的本地自然日：昨日 00:00 到今日 00:00（结束不含）；
- 点“自定义”或直接点范围按钮会打开日历：在月历里点两个日期确定起止，两个时间滚轮
  默认当前时刻，可用鼠标滚轮、上下按钮或方向键微调；
- 设置里的“自定义范围向外吸附到 10 分钟边界”打开时，12:41 会扩到 12:50，范围按钮会
  同步显示实际查询的区间；
- 分析页范围按钮左侧有“全部 / 近 30 日 / 近 7 日 / 昨日 / 今日”快捷预设；
  用日历自定义区间后，预设会自动取消选中；
- 所有区间的结束时间都不含在统计内。

## 每日活跃、活跃天数与使用时长

- **每日活跃卡片有独立的统计区间**（默认近 30 日），点卡片里的日期按钮可单独修改，
  不受上方主统计范围影响；所以主范围只有一天时，也能看到多天的趋势；
- 两个区间重合的日期会铺一层淡蓝底高亮，用来对齐主统计范围；切换主范围时高亮立即更新；
- 每根柱子等长，纵向从 0 点排到 24 点，柱内按 0～23 点分段着色（下方有 0 点—24 点
  色带图例），柱高不再表示总量；鼠标悬停可看次数、使用时长、时段高峰与活跃等级；
- 每天输入达到 **325 次**记为活跃日，达到 **7999 次**记为火热日；这两个数字按每日活跃
  区间统计，卡片下方会标出当前是哪一段区间；选「全部」时写成「全部87日」，
  直接标出这段区间覆盖的自然日数；
- 这里的「输入」是按键、鼠标按键与滚轮手势的次数，**不含滚动距离**：阈值本来就是按
  「1 次 ≈ 一次敲击」定的，一滑几百格混进来会让阈值失去意义（这也是 1.3.5 拆开滚轮口径的原因）；
- 使用时长是“有输入的分钟数”累计，不是从第一次输入到最后一次输入的跨度——
  没有键鼠事件时无法判断用户是否还在电脑前，这样统计更保守；
- **双击概览或分析页的“使用时长”卡片**，可在“最大单位 天 / 小时”之间切换，两处同步；
  不足一天时两种模式数值相同，卡片下方会标出当前模式；
- 日均输入按自然日跨度计算，区间内没有输入的日子也会计入。

## 按键筛选

- 概览与分析的范围行末端都有「按键筛选」按钮，点开是按类别分组的多选列表，
  可以搜索（例如输入 shift、滚轮、f1），勾选想单独看的键；
- 勾选后按钮变成高亮的「已筛选 N 个键」，指标的标签变为「已筛选 · 总输入」，
  分析页副标题会追加「已筛选 N 个键」；
- 跟着筛选走的有：热力图、按键排行榜、类别占比、区间总输入与日均；
  不跟着走的有：活跃天数、使用时长、每日趋势——它们按自然日与分钟统计，
  数据库里没有「每天的每个键」这一层，筛选只看输入量；
- 概览与分析**各自独立**筛选，互不影响；面板底部的「同步到分析页 / 同步到概览页」
  可以把当前选择复制到另一页；
- 不选任何键、或把全部键都勾上，都等于没筛选；「取消筛选」一键恢复；
- 筛选状态不写入设置文件，重启后回到全部按键。

## 滚轮：距离与手势

滚轮记两件互相独立的事，不要把两个数字互相换算：

- **滚动距离**：累计的原始滚动增量（一格 = 120）。它回答「你让屏幕上的东西走了多远」，
  是忠实的原始数据，界面里的「格」和「≈ 厘米 / 米」都是从它算出来的；
- **滑动手势**：你做了几次上滑 / 下滑动作。判定规则是「距同向上一次滚动超过手势窗口
  （默认 200 ms）就算一次新动作」，窗口内的后续事件并入当前动作。上下方向各自计时，
  所以上下来回切换不会被压成一次；
- 手势是**在采集那一刻**判定并写库的（库里只有每分钟聚合，事后无法还原事件序列），
  因此**改窗口只影响之后的新事件**，历史数据里的手势数不会因为调窗口而变化；
- 距离不进「输入次数」：区间总输入、日均、排行榜和类别占比都只数按键、鼠标键与手势，
  不会因为一滑几百格而失真。热力图鼠标一行的滚轮两格画的是手势次数；
- 升级前保存的滚动记录只有「格数」、没有原始 delta：显示距离时会按每格 120 折回一起相加，
  把鼠标停在距离上可以看到其中多少格来自旧口径（最多差不到一格）；旧数据没有手势，
  手势从升级之后开始记录。

估算长度（「≈ 12 cm · 估算」）只用于直观感受量级：一格按 3 行、每行 20 DIP 折算，
96 DPI 基准下约 1.59 cm。屏幕缩放不影响这个估算（DIP 本身就是 DPI 无关的单位），
但系统「每次滚几行」和各个程序自己的滚动实现会影响实际距离，所以它只是一个估算，
不写回任何存储。

## 滚轮校准

设置页的「滚轮采集与校准」只显示当前窗口与系数，点「打开校准…」进入一个盖住整个窗口的
校准界面——找适合自己的手势窗口就在这里：

- **打开即开始测量**：界面右侧实时显示当前方向、本次校准累计的上滑 / 下滑次数与
  原始 delta 累计，但这段滚轮**不写入统计**（键盘和鼠标按键照常统计）。
  侧边栏状态会显示「滚轮校准中」，不会假装成「正在采集」；
- 拖动滑块或点 50 / 100 / 150 / 200 / 300 / 400 / 500 的快捷档改窗口，**立即生效**，
  不用重启；窗口越短越灵敏（滚轮停一下再滚就算新动作），越长越保守（一次连续滑动更难被拆开）；
- 一边滚一边看：如果明明是一次连续滑动却被算成好几次，就把窗口调大；如果每次重新起手
  都被并进上一次，就调小；
- **返回主界面就用「返回主界面」按钮或按 Esc**，两条路都会结束校准、恢复滚轮记录，
  并把判定状态清空（所以恢复后的第一下一定是新动作）。把窗口收进托盘、重启或完整退出
  也会自动结束，不需要特意先回来关一次；
- 「清空校准计数」只清界面读数，不动任何统计；
- 「距离系数」只影响右侧「估算距离」的换算（例如你的系统是「每次滚 5 行」可以适当调大），
  不改变入库数值；屏幕缩放不用管，DIP 单位已经把它抵消掉了。

## 键盘配列

- 热力图支持多套配列，在「设置 → 外观 → 键盘配列」里切换，切换立即生效并记住；
- 内置：全尺寸 104、紧凑全尺寸（带 PrtSc / 无 PrtSc、Ins 两套）、无数字键盘 87、
  75% 84、65% 68、60%。紧凑全尺寸按「有没有 PrtSc / Ins」命名：各家的 98 / 99 键
  排布并不统一，与其写一个不准的键数，不如让名字对得上你键盘上的那几颗键；
- **配列只改画法**：采集、数据库、排行榜、类别占比都按物理键走，换配列不会改变任何数字；
  紧凑配列没画出来的键，热力图副标题会写明「未显示 N 个键」，它们仍然出现在排行榜和
  「全部键位」里；
- 鼠标 7 个键（左 / 中 / 右、侧键 1 / 2、上滑 / 下滑手势）固定画在键盘下方一行，不受配列影响。

### 自定义配列

把 JSON 文件放进程序旁的 `Data\layouts\` 目录，或在设置页点「导入布局…」。
导入时会先校验：重复的键、重叠的键帽、超出画布、写错的键名都会被拒绝并说明原因，
校验不过的文件只是不显示，不影响程序启动。格式如下（坐标单位是 1U）：

```json
{
  "version": 1,
  "id": "my-nav-keys",
  "name": "示例：导航键小键盘",
  "columns": 8,
  "keys": [
    { "key": "Insert", "x": 0, "y": 0 },
    { "key": "Home",   "x": 1, "y": 0 },
    { "key": "PageUp", "x": 2, "y": 0 },
    { "key": "Delete", "x": 0, "y": 1 },
    { "key": "End",    "x": 1, "y": 1 },
    { "key": "PageDown", "x": 2, "y": 1, "w": 2, "label": "PgDn" }
  ]
}
```

- `key` 用按键的英文名（与「全部键位」里显示的名字对应，不区分大小写）；
- `w` / `h` 是键宽与键高（默认 1），`label` 省略时自动用内置短标签；
- `columns` 是画布总宽度，必须能容纳所有键；`id` 决定设置里记的是哪一套，改名不影响。

## 热力图与时段

- 热力图上半部分是键盘键位，最下面一行是鼠标：左键、中键、右键、侧键 1 / 2、滚轮上 / 下，
  键帽样式与键盘完全一致，按下时同样会高亮；
- 「鼠标与滚轮」卡片只保留总量与占全部输入的比例，逐键次数看上图那一行；
- **着色基准**决定“最亮的那个键”从哪一组里挑，可在设置页分别为键盘和鼠标选择
  「键盘」「鼠标」「键盘 + 鼠标」。默认键盘只和键盘比、鼠标和全部输入比；
  把键盘设成「键盘 + 鼠标」时，因为鼠标左键通常远高于任何单个键，键盘会整体变浅——
  这是该口径的正常结果，便于横向比较两边的量级；
- 鼠标停在键帽或时段上会显示次数、占比、排名，以及当前着色基准的最高次数；
- 时段热力图按一天中的 144 个十分钟时段汇总；整条是连续色带，段与段之间不会出现接缝；
  这 10 分钟没有任何输入的段用「未活跃」底色铺着，条带始终连续，不会像被切开；
- 深色模式下热力色阶会整体重映射，起点贴近卡片底色，不会出现一排过亮的键帽。

## 开机自启

- 勾选「登录 Windows 后自动启动」后，Keyana 以当前用户的**普通权限**在登录时静默启动，
  不弹 UAC、不显示窗口，直接进托盘开始统计；
- 如果需要统计以管理员权限运行的游戏或程序，再勾选「以管理员权限自启」：会弹一次 UAC，
  任务改为以最高权限运行；之后登录时同样静默启动，不会每次弹 UAC；
- 管理员自启的任务定义由程序自身的提权 helper 生成并写入只有管理员可写的目录，
  不再经过旧版“普通进程写 %TEMP%、提权进程读取”的路径；
- 取消「登录 Windows 后自动启动」会删除任务；只取消「以管理员权限自启」会保留自启，
  但改回普通权限（不需要 UAC）。

## 重启与完整退出

设置页「采集与数据」卡片最下方的「应用」区：

- **重启 Keyana**：点开后在浮层里选权限——「普通权限重启」或「管理员权限重启」。
  重启会先保存当前这一分钟的数据，关闭当前实例后再启动新实例；
  选管理员权限重启会弹出一次 UAC，取消 UAC 则什么都不发生，程序继续运行；
  当前已经是管理员权限时，「普通权限重启」不可用（Windows 不支持直接降权启动），
  需要普通权限请先完整退出，再从开始菜单或任务栏重新打开；
- **完整退出**：红色按钮，点击后弹出二次确认，确认后停止采集、落盘并退出程序。
  关闭窗口只是收进托盘，只有完整退出才会真正结束进程。

## 数据保存与迁移

- 数据保存在程序旁的 `Data` 目录；
- 完整移动程序文件夹即可迁移数据；
- 完整版与轻量版的数据格式相同，可以直接复制整个 `Data` 目录；
- 如果移动前启用了登录自动启动，请在新位置运行程序后，取消并重新勾选一次，以更新启动路径；
- 1.3.1 之前留下的 `key-stats.db` 会在首次启动时自动迁移为 `keyana.db`：先合并 WAL 中的
  已提交数据再改名，迁移不安全时继续使用旧文件，不会只搬走主库；
- 存储初始化失败时左下角显示“启动失败”，此时不会开始采集（避免出现界面在涨、库里
  没有的假采集）；在设置页点“重试初始化”可重新尝试；
- 保存失败时状态显示“保存异常”，计数仍留在内存中并自动重试，恢复后补写；完整退出时
  还会做最后一次兜底保存。

## 两种版本

- 完整版：内含 .NET 10 桌面运行时，无需安装其他环境；
- 轻量版：文件更小，需要电脑已安装 x64 `.NET 10 Desktop Runtime`。

## 游戏兼容性

如果游戏以管理员权限运行，请先用设置页的「重启 → 管理员权限重启」重启 Keyana（会弹一次 UAC）；
也可以先在设置里勾选「以管理员权限自启」，下次登录后 Keyana 会直接以管理员权限运行。
当前是不是管理员权限，看左下角状态旁边的小字即可。部分采用独占输入或反作弊隔离的游戏
可能不会向普通桌面程序提供输入事件。
