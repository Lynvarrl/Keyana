# 隐私与数据格式

## 不采集的内容

Keyana 不保存：

- 用户实际输入的文本；
- 按键发生的先后顺序；
- 当前应用、窗口标题或进程名称；
- 鼠标坐标或移动轨迹；
- 滚轮滚动的内容（只记录上下方向、累计滚动距离和滑动手势次数）；
- 账号、设备身份或云端同步数据。

## 保存的内容

程序只保存一分钟内各物理按键、鼠标左右键 / 中键 / 侧键的累计次数，滚轮的上滑 / 下滑
手势次数，以及滚轮上下两个方向的累计原始增量（一格 = 120，用来表示「滚了多远」）。
界面中的十分钟统计、每日活跃（含逐小时时段分布）与使用时长均由分钟数据派生。

距离与次数分开存：滚轮距离不进计数向量，避免被当成「输入次数」求和。

数据位于程序旁的 `Data` 目录：

- `keyana.db`：SQLite 聚合数据库；
- `settings.json`：本地设置。

程序使用 SQLite WAL，因此运行期间还可能出现 `keyana.db-wal` 和 `keyana.db-shm`。

## 迁移与删除

- 迁移：完整复制程序文件夹或 `Data` 目录；
- 删除全部记录：完整退出程序后删除 `Data` 目录；
- 卸载登录自启动：先在界面取消勾选，再删除程序文件夹。
