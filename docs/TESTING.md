# 测试范围

自动回归测试覆盖：

- 标准键、左右修饰键、主键区和数字键盘归一化；
- F13–F24、媒体键和未知键；
- 长按去重、组合键、多键盘和设备移除；
- Alt+Tab 补偿与重复计数保护；
- 鼠标左右键 / 中键 / 侧键、暂停和本次清零；
- 滚轮手势的静默窗口合并、上下方向独立计时、零增量与 Reset；
- 滚轮距离按 120 折算与厘米估算，距离不进入次数统计；
- 滚轮距离与手势判定互不干扰、距离随分钟桶一起落库；
- 昨天区间与今天首尾相接；
- 逐日汇总的活跃日/火热日阈值、使用时长、逐小时时段分布与空日补齐；
- 稀疏计数编码兼容性（含 v6 新键位与旧数据解码）；
- SQLite 分钟写入、绝对快照和跨重启累计；
- schema v1 → v2 迁移：老库自动补两列、旧行数据保留、距离列可写；
- 全部范围边界、十分钟汇总和时段序列；
- 历史总数量；
- CSV 导出、设置文件与损坏设置的降级。

发行前还应在 Windows 10/11 手动验证托盘、登录自启动、窗口隐藏、完整退出、不同时间范围及 DPI 缩放。
